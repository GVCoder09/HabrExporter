## Описание

**HabrExporter** - это настольное приложение на PyQt6, которое сохраняет статью с [Хабра](https://habr.com) на ваш компьютер в виде **PDF**, **HTML**, **DOCX**, **EPUB**, **FB2** или **Markdown** вместе с комментариями, изображениями и с оформлением, повторяющим сайт. Для обработки программами есть **JSON**: данные статьи и комментариев без оформления.

### Ключевые преимущества и возможности

Программа работает в двух режимах: сохранение одной статьи и пакетное сохранение. В последнем режиме можно сохранить весь блог автора, закладки другого пользователя или список ссылок из файла.

Основные форматы - PDF, HTML и JSON. DOCX, электронные книги EPUB и FB2 и Markdown пока в бете: их оформление может отличаться от сайта.

В сохранённом файле есть статья с разметкой (заголовки, списки, таблицы, спойлеры, формулы, код с подсветкой синтаксиса, изображения с подписями), карточки автора и компании, теги, хабы, рейтинг и все комментарии деревом, как на сайте.

## Быстрый старт

Скачайте последнюю версию для вашей ОС из [последнего релиза](https://github.com/GVCoder09/HabrExporter/releases/latest), распакуйте в любое место и запустите.

## Установка через pip

> [!IMPORTANT]
> Убедитесь, что установлен Python 3.11+
>

Выполните `pip install git+https://github.com/GVCoder09/HabrExporter.git`

Будут установлены две команды: `habr-exporter` (GUI) и `habr-exporter-cli` (командная строка).

В Linux для Qt WebEngine нужны обычные библиотеки рабочего стола (OpenGL/EGL, NSS, X11/xkb). В любой настольной системе они есть; для минимальной системы или системы без графической оболочки смотрите список пакетов в [.github/workflows/ci.yml](.github/workflows/ci.yml).

**Для разработки** смотрите [CONTRIBUTING.md](CONTRIBUTING.md).

## Запуск

Графическое приложение:

```bash
habr-exporter
```

Если пакет не установлен как команда, используйте `python -m habr_exporter`. Ссылку можно передать сразу (`habr-exporter https://habr.com/ru/articles/123456/`), и статья начнёт загружаться при запуске.

### Работа в окне (режим «Одна статья»):

1. Вставьте ссылку на статью (можно просто номер) и нажмите **Загрузить** (или Enter). Появятся предпросмотр и карточка статьи.
2. Выберите **формат**: PDF (по умолчанию), HTML, DOCX, EPUB, FB2, MD или JSON.
3. Выберите **изображения**: **Встроить в файл** (скачиваются, файл открывается без интернета) или **Ссылками на Хабр** (файл меньше).
4. При необходимости отключите **Комментарии**.
5. Нажмите **Сохранить** (Ctrl+S) и выберите, куда положить файл.

Тема (как в системе, светлая или тёмная) и язык (русский или английский) переключаются кнопками в правом верхнем углу. Выбранные формат, режим изображений, тема и язык запоминаются между запусками.

### Пакетная выгрузка

<p align="center">
  <img src="docs/images/batch-export.webp" alt="Habr Exporter: пакетная выгрузка статей автора с прогрессом и журналом" width="900" />
</p>

Вкладка **«Несколько»** сохраняет много статей в папку за один раз. Источники:

* **Закладки**: все публичные закладки пользователя (`boomburum`, `@boomburum` или ссылка на профиль);
* **Статьи автора**: все его статьи и новости;
* **Файл ссылок**: текстовый файл со ссылкой или номером статьи на каждой строке (`#` начинает комментарий).

Выберите папку, формат и режим изображений и нажмите **Начать**. Справа показываются ход выгрузки и журнал
сохранённых, пропущенных статей и статей с ошибкой; их можно повторить, а **Остановить** прерывает
выгрузку после текущей статьи.

* Имя файла начинается с номера статьи: `1094766 - Заголовок.pdf`.
* Статьи, которые уже лежат в папке в этом формате, пропускаются, поэтому при повторном запуске скачиваются только новые
  (инкрементальная резервная копия).
* Статья, которую не удалось сохранить (удалена, скрыта, ошибка сети), не прерывает выгрузку.
* В конце в папке появляется `index.html` со списком всех статей, отсортированных по дате, сначала новые.
* **Сколько статей** ограничивает выгрузку последними N; **Пауза между запросами** (по умолчанию 1 секунда, 0 - без паузы) не даёт перегрузить Хабр.

### Режим командной строки

```bash
habr-exporter-cli https://habr.com/ru/articles/123456/ -f html -i embed -o ./saved/
```

| Параметр | Значение |
|---|---|
| `url` | ссылка на статью или её номер |
| `-f`, `--format` | `pdf` (по умолчанию), `html`, `docx`, `epub`, `fb2`, `md`, `json` |
| `-i`, `--images` | `embed` (по умолчанию) или `link` |
| `-o`, `--output` | файл или папка; по умолчанию текущая папка |
| `--no-comments` | не сохранять комментарии |
| `-q`, `--quiet` | не выводить ход выполнения |
| `-V`, `--version` | вывести версию и выйти |

Путь к сохранённому файлу выводится в stdout, ход выполнения и ошибки - в stderr. Код возврата: `0` - сохранено, `1` - ошибка.

Пакетная выгрузка: укажите источник вместо ссылки, а в `-o` - папку.

```bash
habr-exporter-cli --bookmarks boomburum -f pdf -o ./bookmarks/
habr-exporter-cli --author boomburum -f html --delay 2 -o ./boomburum/
habr-exporter-cli --from-file links.txt -f docx -o ./saved/
```

| Параметр | Значение |
|---|---|
| `--bookmarks USER` | все публичные закладки пользователя |
| `--author USER` | все статьи и новости автора |
| `--from-file PATH` | ссылки из текстового файла, по одной на строку |
| `--delay SEC` | пауза между запросами к Хабру, по умолчанию `1` |
| `--limit N` | сохранить не больше N последних статей |

Параметры `-f`, `-i`, `--no-comments` и `-q` работают так же, как для одной статьи. Код возврата: `0` -
всё сохранено, `2` - часть статей не сохранена, `1` - не удалось получить список, `130` -
прервано по Ctrl+C.

## Чем отличаются форматы

| | PDF | HTML | DOCX (бета) | EPUB (бета) | FB2 (бета) | Markdown (бета) | JSON |
|---|---|---|---|---|---|---|---|
| Вид | страницы A4 в оформлении Хабра | точная копия оформления Хабра | стили Word, близкие к Хабру | как на Хабре; шрифт и ширину выбирает читалка | собственное оформление читалки | как покажет программа просмотра; YAML-заголовок | без оформления: поля, очищенный HTML и простой текст |
| Оглавление | нет | нет | нет | разделы, автор, комментарии | разделы, автор, комментарии | заголовки `##` | нет |
| Код | с подсветкой | с подсветкой | с подсветкой | с подсветкой | моноширинный | блоки ```` ``` ```` с языком | `<pre><code>` в HTML |
| Спойлеры | раскрыты | сворачиваются | раскрыты, с отступом | раскрыты, линия слева | раскрыты, как цитата | `<details>` | `<details>` в HTML |
| Комментарии | дерево | дерево | дерево | дерево, отдельная глава | ответы цитатами со стрелкой «↳» | вложенные цитаты `>` (до 5 уровней) | плоский список, дерево через `parent_id` |
| Редактируется | нет | нет | да | нет | нет | да | — |
| Изображения: встроить | внутри PDF | `data:`-URI | в документе | файлы в книге | PNG или JPEG в файле; без аватаров и логотипа | `data:`-URI, собранные в конце | не встраиваются: только URL в `images` |
| Изображения: ссылками | подгружаются с Хабра при печати, сохраняются в PDF | `<img>` грузит с Хабра | связанная картинка, Word загружает её с Хабра при открытии | ссылка 🖼 | ссылка 🖼 | `![](url)` | только URL |

* WebP и SVG преобразуются в PNG там, где формат не умеет их показывать.
* Если изображение не скачалось, сохранение продолжается: HTML и Markdown оставляют его URL, остальные форматы
  показывают ссылку на оригинал.
* В режиме «Ссылками» EPUB и FB2 показывают ссылку 🖼 вместо изображения: они не могут (или не должны) грузить
  изображения из сети при открытии. DOCX всё равно встраивает то, что Word не умеет подключать по ссылке (WebP, SVG-формулы).
* Видео и другие встроенные плееры нельзя сохранить для просмотра без интернета, поэтому вместо них показывается ссылка.

### Markdown для заметок и вики

CommonMark с расширениями GitHub (таблицы, зачёркивание) для Obsidian, Logseq, вики или
репозитория. Файл начинается с YAML-заголовка (`title`, `url`, `author`, `published`, `hubs`,
`tags`…). Формулы - это TeX (`$…$`, `$$…$$`).

Встроенные изображения - это `data:`-URI, но в тексте только короткие ссылки `![подпись][img-1]`, а
сами данные лежат в конце файла. Obsidian, Typora и VS Code их показывают; GitHub - нет, поэтому для него
используйте `-i link`:

```bash
habr-exporter-cli 1094766 -f md -i link -o article.md
```

### JSON для программ

Машиночитаемая статья: метаданные, хабы, теги, счётчики, карточки автора и компании, текст
(`body_html` и простой текст `body_text`), список изображений и комментарии. Даты в формате ISO 8601
с часовым поясом, отсутствующие значения - `null`.

* Изображения никогда не скачиваются и не встраиваются: в `images` только URL (и `alt`), а режим изображений
  значения не имеет.
* Комментарии - плоский список в порядке сайта с `parent_id` и `level`; при `--no-comments` поле
  равно `null`.

```bash
habr-exporter-cli 1094766 -f json -o article.json
jq -r '.article.comments[] | select(.parent_id == null) | .text' article.json
```

Схема (`"schema": "habr-exporter/article"`, `"version": 1`) описана в
[docs/architecture.md](docs/architecture.md#json-exportersjsonpy).

## Ограничения

* Используется публичный JSON API сайта (`habr.com/kek/v2`). Он неофициальный: если Хабр его изменит, парсер придётся обновлять.
* Черновики и удалённые статьи сохранить нельзя: API возвращает ошибку.
* Пакетный режим видит только публичные закладки: приложение не поддерживает вход в аккаунт.

## Сообщения об ошибках

Нашли ошибку или статью, которая сохраняется неправильно? Создайте [issue](https://github.com/GVCoder09/HabrExporter/issues) и приложите ссылку на статью, формат и текст ошибки. Хабр иногда меняет вёрстку, и такие сообщения помогают быстро исправить парсер.
